# QR・画像変換ミニツール（qrimage）

「QR コード生成や画像形式変換を検索すると広告だらけのサイトが出てくる」という不満に応える、広告なし・登録不要の小さな道具ページです。

## 使い方

- **QR コード生成**：テキストや URL を入力すると QR コード PNG を表示します。そのままダウンロードもできます（`GET /api/qr?text=...` でも PNG を返します）。
- **画像変換**：PNG / JPEG / WebP の画像ファイル（5MB まで）をアップすると、PNG または JPEG に変換してダウンロードできます。JPEG 変換時は透明部分は白で塗りつぶされます。

アップロードしたファイルはサーバーに保存せず、メモリ上で処理して返します。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- QR コードは標準的な誤り訂正レベルで生成します。容量を超える長文はエラーになります。
- 画像変換は形式変換のみです。リサイズ・圧縮率の細かい指定・一括変換には対応していません。
- アップロード上限は 5MB です。大きな写真の変換には向きません。
- ログイン機能はありません（そもそもデータを保存しません）。
